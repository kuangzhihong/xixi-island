# 茜茜的小岛 🌸

一个面向小学生的**单文件**学习工作台。整个应用只有一个 HTML 文件，内联了样式、脚本和全部内容数据，打开即用、可离线运行、支持「添加到主屏幕」当 App 使用。

- **在线体验**：https://xixi-workbench-15382.app.workbuddy.host/
- **当前版本**：v1.9.17
- **源码仓库**：https://github.com/kuangzhihong/xixi-island（公开库，仅含源码与部署产物，不含个人数据）

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `xixi-workbench.html` | 主源码（整个应用就这一个文件） |
| `xixi-app/` | 部署目录：`index.html`（主源码副本）、`sw.js`（离线缓存）、`manifest.webmanifest`、`icons/` |

## 主要模块

- **每日任务**：语文 / 数学 / 英语按年级出题，做完打卡可得 ☀️阳光 与 💎钻石
- **语文**：古诗、故事、阅读理解、千字文（全文带**拼音标注**）、汉字听写、跟读朗读与录音对比
- **数学**：口算、思维应用题、乘法练习、图画学数学、解法学数学（凑十 / 平十 / 破十等）、数独
- **英语**：单词、字母跟读、情景对话
- **闯关游戏**：口算、看图猜词语、数独、古诗配对、汉字听写、英语单词、成语填空、海龟汤（每题 10 关，全对通关）
- **考试**：按年级与教材册次生成语文 / 数学 / 英语试卷
- **其它**：云宠养成、小花园、皮肤装扮、学习统计

所有题库都带**年级标记**，按所在年级与教材册次过滤，低年级不会考到高年级内容。

## 本地运行

直接用浏览器打开 `xixi-workbench.html` 即可，无需安装任何依赖。

> `file://` 协议下**录音跟读**不可用（浏览器安全限制），其余功能正常。
> 需要完整体验（录音 / Service Worker 离线）时，请用 HTTPS 或 localhost 提供服务。

## 数据与隐私

- 学习数据保存在**浏览器本地**（`localStorage`），**不会上传到任何服务器**。
- 内置三层保护：每日自动快照、手动导出 JSON 备份、从备份/快照回退。
- 数据跟随单台设备，**换设备不会自动同步**，需手动导出再导入。

## 离线使用

手机浏览器打开在线地址 → 「添加到主屏幕」，即可全屏离线使用（Service Worker 已配置）。
